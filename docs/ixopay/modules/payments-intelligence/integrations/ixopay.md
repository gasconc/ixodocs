# IXOPAY
IXOPAY () is a leading payment orchestration platform that streamlines global online payments for enterprise-level businesses. Designed for scalability and flexibility, IXOPAY enables merchants to connect to hundreds of payment service providers and methods through a single, unified API.
It offers intelligent transaction routing, secure tokenization, PCI-compliant data management, and advanced fraud-prevention tools — ensuring optimized approval rates, lower processing costs, and enhanced reliability. IXOPAY also provides automated reconciliation, comprehensive reporting, and support for subscription billing, making it an ideal solution for international e-commerce companies, marketplaces, and recurring-revenue businesses.
## How to connect with Ixopay[​](https://documentation.ixopay.com/modules/docs/payments-intelligence/integrations/ixopay#how-to-connect-with-ixopay "Direct link to How to connect with Ixopay")
To integrate IXOPAY with IXOPAY Payments Intelligence (formerly Congrify), you will need to provide the following credentials:
  * Merchant Account Name
  * API Key
  * API Key Password

For detailed guidance on how to obtain these credentials, refer to the [API Keys](https://docs.ixopay.com/manual/docs/system-setup/api-keys) page in the IXOPAY User Manual.
### Find your API Key & API Key Password[​](https://documentation.ixopay.com/modules/docs/payments-intelligence/integrations/ixopay#find-your-api-key--api-key-password "Direct link to Find your API Key & API Key Password")
To create your API Key and API Key Password in IXOPAY, follow these steps:
  1. Log in to the IXOPAY portal and navigate to System Setup → API Keys.
![](https://documentation.ixopay.com/modules/assets/ideal-img/ixopay_tenant_api_keys.0c05a2c.760.png)
  2. Click New API Key, then select BDS (BI Data Source) under the Services section.
![](https://documentation.ixopay.com/modules/assets/ideal-img/ixopay_create_new_api_keys.225a950.871.png)
  3. After creating the key, your API Key and API Key Password will be displayed. This is the only time the password will be visible, so make sure to securely store it before closing the window.
![](https://documentation.ixopay.com/modules/assets/ideal-img/ixopay_Api_key_successful.166c4dc.1600.png)
  4. Enter your credentials in the IXOPAY Payments Intelligence → Connections → IXOPAY Connection section.

### Importing Historical Data[​](https://documentation.ixopay.com/modules/docs/payments-intelligence/integrations/ixopay#importing-historical-data "Direct link to Importing Historical Data")
During onboarding, you may choose to import historical transaction data from IXOPAY into IXOPAY Payments Intelligence.To initiate this process, please contact the support team or your designated account representative.
