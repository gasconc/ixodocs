# Chargebee
Chargebee () is a subscription management and recurring billing platform that helps businesses automate invoicing, payments, and revenue operations. It supports various payment gateways, tax compliance, and analytics, making it a popular choice for SaaS, eCommerce, and other subscription-based businesses. Chargebee integrates with multiple financial and CRM tools, streamlining the entire subscription lifecycle.
## How to connect with Chargebee[​](https://documentation.ixopay.com/modules/docs/payments-intelligence/integrations/chargebee#how-to-connect-with-chargebee "Direct link to How to connect with Chargebee")
To connect with Chargebee please contact the support team.
### Required access credentials[​](https://documentation.ixopay.com/modules/docs/payments-intelligence/integrations/chargebee#required-access-credentials "Direct link to Required access credentials")
  1. Name  
The name of Chargebee's Account
  2. API Key  
The API Key on the Chargebee platform to ingest data for
  3. Site  
The URL of your Chargebee account.

### Importing Historical Data[​](https://documentation.ixopay.com/modules/docs/payments-intelligence/integrations/chargebee#importing-historical-data "Direct link to Importing Historical Data")
During the onboarding process with IXOPAY Payments Intelligence (formerly Congrify), you can import historical data from Chargebee. Please reach out to the IXOPAY Payments Intelligence team to confirm which data can be historically downloaded.
## Available Reports[​](https://documentation.ixopay.com/modules/docs/payments-intelligence/integrations/chargebee#available-reports "Direct link to Available Reports")
The following reports are available for the Chargebee integration and will provide the necessary data for a successful integration with IXOPAY Payments Intelligence. Please ensure that you select these reports as a minimum when configuring your Chargebee connection:
  * Credit Note report
  * Invoice Report
  * Order Report
  * Subscription Report
  * Transaction Report
