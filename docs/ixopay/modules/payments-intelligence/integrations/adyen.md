# Adyen
Adyen () is a leading global payment platform that provides businesses with a seamless way to accept payments online, in-app, and in-store. Known for its all-in-one solution, Adyen supports a wide range of payment methods and currencies, enabling companies to scale internationally with ease. Its advanced features, such as real-time data insights, fraud prevention, and a unified payment system, empower businesses to optimize their payment processes while delivering a smooth customer experience. Trusted by major global brands, Adyen is a preferred choice for companies seeking innovative and reliable payment solutions.
## How to connect with Adyen[​](https://documentation.ixopay.com/modules/docs/payments-intelligence/integrations/adyen#how-to-connect-with-adyen "Direct link to How to connect with Adyen")
To integrate Adyen with IXOPAY Payments Intelligence (formerly Congrify), you must create a Reporting User and configure a Webhook. Below are the detailed steps for each process.
### Creating a Reporting User[​](https://documentation.ixopay.com/modules/docs/payments-intelligence/integrations/adyen#creating-a-reporting-user "Direct link to Creating a Reporting User")
To create a Reporting Service User:
  1. Navigate to Developers > API Credentials in the Adyen dashboard.
  2. Select Create new credentials and set the credentials type to Report Service User.
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_credentials_1.dd9560a.1600.png)
  3. Save the username and password (Basic Auth option) generated by Adyen in IXOPAY Payments Intelligence.
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_credentials_2.4b4ba1b.1600.png)

### Configuring Webhooks[​](https://documentation.ixopay.com/modules/docs/payments-intelligence/integrations/adyen#configuring-webhooks "Direct link to Configuring Webhooks")
  1. **Create a New Webhook** Navigate to Webhooks > Create new webhook and add a Standard Webhook.
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_webhook_1.49b999e.1600.png)
  2. **Set Up the Server Configuration**

  * Create a Username and Password, then generate the HMAC Signature.
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_webhook_3.54b02f9.1570.png)
  * Insert your Adyen credentials, including HMAC key generated, on the Ixopay Payments Intelligence platform.(User Profile → Connections → Adyen 'Add Provider', and create the server configuration URL)
![](https://documentation.ixopay.com/modules/assets/ideal-img/Adyen_update_webhook.7f25802.1600.png)
  * Enter the Server configuration URL provided by IXOPAY Payments Intelligence, for webhook configuration on Adyen.
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_webhook_2.158f97d.1570.png)
  * Select only the REPORT_AVAILABLE webhook event.
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_webhook_4.116c917.1260.png)
  * Save these details in IXOPAY Payments Intelligence.

  3. **Enable Automatic Report Generation**
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_webhook_5.a115099.1600.png)
Enable the Automatic generation for the following reports:
     * 3DS Authentication
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_report_3DS_authentication.b4e3fd9.1600.png)
     * Dispute transaction details
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_reports_dispute.b949e3a.1600.png)
     * Payment accounting
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_reports_payment_accounting.9cf15cc.1600.png)
     * Received payments details
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_reports_received_payments.819fad0.1600.png)
     * Settlement details
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_reports_settlement_details.b6e3a53.1600.png)
  4. **Test the Webhook**
     * Generate a report manually by clicking Generate.
     * Check System messages to confirm the webhook was successfully received.
![](https://documentation.ixopay.com/modules/assets/ideal-img/adyen_webhook_6.02d99f8.1539.png)

### Importing Historical Data via SFTP[​](https://documentation.ixopay.com/modules/docs/payments-intelligence/integrations/adyen#importing-historical-data-via-sftp "Direct link to Importing Historical Data via SFTP")
During the onboarding process with IXOPAY Payments Intelligence, you can import historical data from Adyen. The most efficient method is to grant the IXOPAY Payments Intelligence team access to the shared SFTP folder with Adyen. This allows IXOPAY Payments Intelligence to directly select and import the desired historical data.
## Available Reports[​](https://documentation.ixopay.com/modules/docs/payments-intelligence/integrations/adyen#available-reports "Direct link to Available Reports")
The following reports are essential for the Adyen integration. These reports will provide the necessary data for a successful integration with IXOPAY Payments Intelligence.Please ensure that you select these reports as a minimum when configuring your Adyen connection:
  * Payments Accounting Report
  * Received Payments Report
  * Settlement Details Report
  * Dispute Details Report
  * 3DS Authentication Report
  * Monthly Invoices
